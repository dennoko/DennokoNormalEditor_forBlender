# Dennoko Normal Editor for Blender

VRChat アバター改変・キャラクターモデリング向けの、**モディファイヤー保持型・非破壊プロポーショナル法線編集拡張機能**です。  
Unity 版 **Dennoko Normal Editor** の操作体験をそのまま Blender（4.5 / 5.0 以降）上で再現し、3Dビュー上で直観的に法線を調整して、顔の影の落ち方やハイライト、頭と体などの別メッシュ間の継ぎ目（法線割れ）をきれいに整えられます。

## 必要環境

- **Blender 4.5.0 以降**（Blender 5.0 対応）

---

## Quick Start

### 1. 編集モードの開始
1. オブジェクトモードで編集したいメッシュ（`Face` と `Body` など複数選択可）を選択します。
2. 右クリックメニューから **`Dennoko Normal Editor`** を選択するか、3Dビュー右側の N パネル（`Dennoko` タブ）の **「編集」** ボタンを押します。
3. 選択された各メッシュに `DennokoNormalEditor` モディファイヤー（Geometry Nodes）が自動追加され、即座に編集セッションが始まります。

### 2. 編集操作
- **頂点をクリック：** 見えている表面の頂点を選択します（青い円が影響範囲、法線ピンが現在の法線方向と影響度を示します）。
- **3Dハンドルをドラッグ：** 選択頂点の法線先端にある 3D ハンドル（中央の白/黄ドットで自由方向、赤/緑/青の矢印で X/Y/Z 軸拘束）を引っ張り、影響範囲内の法線を減衰付きで傾けます（Tilt）。
- **ハンドルを掴んだままマウスホイール：** 影響範囲の半径をその場で変更できます（上で縮小、下で拡大）。
- **右下パネルのスライダー / ボタン：**
  - **なじませる（Smooth）：** 周囲の頂点（別メッシュ間の首の境界や UV シームを含む）と法線を平均化して滑らかにつなぎます。
  - **形状を戻す（Restore Shape）：** 球面法線などで平坦になりすぎた顔に対し、ポリゴン本来のスムーズな立体形状法線（Smooth Geometric Normal）を任意の割合でブレンドして鼻筋や唇の立体感を引き出します。
  - **揃える（Flatten）：** 範囲内の法線を選択頂点の法線方向へ均一に揃え、アニメ調のフラットな面を作ります。
  - **元に戻す（Erase）：** 選択範囲内の編集デルタを未編集状態（0%）へ戻します。
- **やり直し（Undo / Redo）：** 編集中に `Ctrl+Z` / `Ctrl+Shift+Z`（または `Ctrl+Y`）で 1 操作ずつ元に戻せます。
- **終了：** `Esc` キーを押す（頂点選択中は選択解除、未選択時は編集終了）か、右下パネルの `[×]` / Nパネルの「編集終了」ボタンを押します。

## 特徴と仕組み

- **純粋なモディファイヤー保持（`Set Mesh Normal` `TANGENT_SPACE` 方式）：**
  - 各メッシュの頂点属性 `_dne_delta` にローカル差分を保持し、Geometry Nodes の `Set Mesh Normal (TANGENT_SPACE)` で適用します。
  - `Armature` モディファイヤーの手前に自動配置されるため、ボーンでポーズを付けたりシェイプキーを動かしてもカスタム法線が破綻せず自然に追従します。
  - 未編集の頂点（デルタ = 0）では既存のシャープエッジや分割カスタム法線が 100% そのまま維持されます。
- **シェイプキーを壊さないベイク・直接適用：**
  - Nパネルの **「ベイク (`_edited` 複製出力)」** で編集適用済みの複製メッシュを生成できます。
  - **「モディファイヤーを適用 (シェイプキー保持)」** を使えば、Blender 標準では不可能な「シェイプキーを持つメッシュへのモディファイヤー適用」を、`normals_split_custom_set` 経由でシェイプキーを一切失わずに直接焼き込めます。
- **UV0 強度マスク対応：**
  - Nパネルの対象リストで各メッシュにマスク画像（`Image`）を設定すると、UV0 の明るさ（白 = 100%、黒 = 0%）に応じて編集強度を制限できます。
